**프로젝트 유형:** 단편 영상

#### 📖 프로젝트 개요

〈잔향〉은 지나간 선택과 그 이후에 남는 감정을
중심으로 이야기를 풀어내는 단편 영상 프로젝트입니다.

선택의 순간과 시간이 흐른 뒤에도 남아 있는
감정의 흔적을 영상으로 표현하고자 했습니다.
